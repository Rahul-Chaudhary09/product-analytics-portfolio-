# Aggregate Functions

## Topics Covered

- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

## Business Skills Learned

- Total Orders
- Total Revenue
- Average Order Value
- Highest Purchase
- Lowest Purchase
- Revenue Analysis using Filters

## Key Learnings

- COUNT() helps measure activity volume (orders, users, events).
- SUM() helps calculate business metrics like revenue and sales.
- AVG() helps understand average customer behavior and spending.
- MAX() identifies top-performing transactions or users.
- MIN() identifies the smallest transaction values.
- Aggregate functions can be combined with WHERE to analyze specific customer segments.
- Business questions can be translated into SQL using aggregate functions.
- Analysts use these functions daily to build KPIs and dashboards.
