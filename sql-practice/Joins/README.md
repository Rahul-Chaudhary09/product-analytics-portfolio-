## Key Learnings

* JOIN combines data from multiple tables using a common column.
* INNER JOIN returns only matching records from both tables.
* LEFT JOIN returns all records from the left table and matching records from the right table.
* GROUP BY helps calculate metrics for each customer.
* HAVING filters aggregated results after grouping.
* NULL values help identify missing activity such as users who never placed an order.
* JOINs are one of the most important SQL concepts for Product Analytics.
